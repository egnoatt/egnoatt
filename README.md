## Working Principles

1. **Clarity before automation**  
   Tools should make decisions easier to understand, not harder to explain.

2. **Human judgment stays central**  
   AI should support analysis and execution without replacing accountability.

3. **Traceability where decisions matter**  
   Important choices should remain understandable, reviewable, and easy to revisit.

4. **Small tools before large systems**  
   A focused workflow that people actually use is more valuable than an oversized platform.

5. **Practical outcomes over technical display**  
   The goal is better work, clearer priorities, and maintainable execution.
